微型生态实验室｜运行与体验说明

《微型生态实验室》是一款浏览器交互程序。你可以添加植物、食草动物和捕食者，调整植物生成速度，观察它们的数量如何随时间变化。

【如何开始】
方式一：打开作品的 GitHub Pages 链接，即可在浏览器中体验。
作品链接：【https://jmf42p7bp5-ops.github.io/eco-lab/】

方式二：下载项目文件后，确保 index.html、style.css 和 app.js 位于同一个文件夹，再用浏览器打开 index.html。

本作品无需安装软件，建议使用较新版本的 Chrome、Edge 或 Safari 浏览器。

【如何操作】
1. 点击“开始模拟”，观察画布中的生物活动和实时数量。
2. 选择植物、食草动物或捕食者工具，再点击生态区域添加生物。
3. 调整滑块，改变植物生成速度或模拟运行速度。
4. 点击“暂停模拟”，可以停下来查看数量曲线和最近事件。
5. 选择“观察动物”工具，点击画布中的动物，查看它的能量与繁殖状态。
6. 想重新尝试时，点击“重置世界”。

你也可以按照页面上的新手引导操作，或尝试让三类生物连续共存 60 个模拟秒的挑战。

【遇到问题怎么办】
如果网页打开后没有显示生物，或按钮点击后没有反应，请先刷新页面，并确认三个项目文件位于同一文件夹。如果使用的是线上链接，可以稍等片刻后重新打开。

【体验提醒】
生物数量减少或某一类生物消失，不一定是程序故障，也可能是进食、能量消耗和捕食等模拟规则造成的结果。你可以调整条件，重新观察。

本作品是用于探索生态关系的简化互动模型，不用于科学预测。感谢体验！
